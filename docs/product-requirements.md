# 1\. 产品概述

## 1\.1 产品定位

一款面向个人的美食记录与可视化工具：用户通过拍照、录入菜品信息、标记地理位置，将所有美食体验以标记点形式聚合呈现在地图上，形成专属的"味觉地图"。产品强调极简操作、数据私有、视觉愉悦，帮助用户沉淀美食记忆、发现周边好店、回顾用餐体验。

## 1\.2 产品背景

大众点评、小红书等平台虽信息丰富，但属于公共UGC，存在广告干扰、评分失真、个人记录分散等问题。个人美食爱好者需要一个纯净的、完全属于自己的美食记录空间，能够快速记录、直观检索、长期沉淀，且不被社交压力和算法推荐打扰。本产品从个人工具切入，先满足核心记录需求，再逐步扩展数据价值。

## 1\.3 核心价值主张

- **极简记录**：拍照 \+ 选点 \+ 保存，3步完成一条美食记录

- **地图可视化**：所有美食足迹一图览，直观发现"美食盲区"

- **数据私有**：本地优先，数据完全由用户掌控，无社交压力

- **多维检索**：按位置、标签、评分、价格、时间等多维度筛选回忆

- **长期沉淀**：支持数据导出备份，记录可永久保存

# 2\. 产品目标与范围

## 2\.1 产品目标

**核心目标**：让用户以最低操作成本（拍照 \+ 选点）沉淀个人美食足迹，并在地图上直观检索、多维筛选。

**阶段目标**：

- **MVP（v1\.0）**：满足个人单机使用，验证核心记录闭环，支持多图、标签、筛选、统计、数据备份等完善功能

- **v1\.5**：增加PWA离线支持、键盘快捷键、暗色模式、批量操作等体验增强

- **v2\.0（远期）**：支持多用户、选择性分享、美食地图导出、餐厅收藏夹同步

## 3\.2 页面布局说明

**桌面端布局**：采用经典的地图\+侧栏双栏布局。地图占满全屏，左侧侧栏宽度360px，可折叠收起。顶部工具栏悬浮在地图上方，毛玻璃效果。添加/编辑表单从右侧滑出抽屉，宽度480px。

**响应式适配**：屏幕宽度小于768px时，侧栏改为底部抽屉式，表单改为全屏模态。工具栏自适应收缩为图标按钮。

## 3\.3 主要页面流

1. **默认进入**：地图主视图 → 自动定位到上次查看位置 → 加载所有记录并打点 → 侧栏显示最新记录列表

2. **新建记录**：点击"新建"按钮 → 右侧抽屉滑出表单 → 填写信息 → 保存 → 抽屉关闭 → 地图飞到新点位置并高亮动画

3. **查看详情**：点击地图Marker或列表项 → 地图居中并弹出信息卡片 → 点击卡片展开完整详情

4. **筛选搜索**：点击筛选 → 设置条件 → 地图和列表实时更新 → 显示匹配结果数量

# 4\. 核心功能详细说明

## 4\.1 记录管理

**新建记录**：支持从顶部按钮、快捷键\(Ctrl\+N\)、列表底部快速新建三种入口。表单支持自动保存草稿，意外关闭不丢失内容。

**编辑记录**：复用新建表单，预填原有数据。修改后实时保存，支持Ctrl\+S快捷键。图片支持单独删除、替换、拖拽排序。

**删除记录**：采用软删除机制，删除后显示5秒撤销提示。超过30天自动清理，也可在回收站手动永久删除。支持批量选择后批量删除。

**图片处理**：

- 支持JPG/PNG/WebP/HEIC格式，单张最大10MB，单次最多9张

- 上传前自动压缩（长边1920px，质量85%），生成200x200缩略图

- 支持拖拽排序、设为封面、单独删除

- EXIF信息提取：自动读取GPS坐标、拍摄时间，一键填充表单

- 图片懒加载，视口外图片不加载

## 4\.2 位置系统

**地址搜索**：集成高德inputtips，输入关键词实时联想。支持搜索餐厅名、地址、地标。选中后自动填充经纬度和详细地址。

**地图选点**：搜索结果不准确时，可直接在地图上点击落点。落点后自动逆地理编码获取地址文本。支持拖拽Marker微调位置。

**快速定位**：点击定位按钮获取浏览器当前位置（需用户授权），自动落点。支持"我在这里"快速记录。

**历史地址**：自动记录使用过的餐厅，下次输入时优先显示。支持收藏常用地址。

## 4\.3 标签与分类

**标签系统**：用户可完全自定义标签，每个标签可设置名称、颜色、图标。一条记录可关联多个标签。预置常用标签：川菜、粤菜、日料、火锅、烧烤、咖啡、甜点等。

**用餐类型**：固定选项：早餐、午餐、晚餐、夜宵、下午茶、加餐、零食。用于时间维度统计。

**价格记录**：记录人均消费（整数元），用于价格分布统计和价格区间筛选。

## 4\.4 地图可视化

**Marker聚合**：当地图缩放级别较低、多个Marker重叠时，自动聚合成数字圆圈。点击聚合圈自动放大到该区域。聚合数字颜色根据数量梯度变化。

**Marker样式**：默认使用餐饮图标，不同标签可设置不同颜色Marker。收藏的记录使用星形图标。

**信息窗**：点击Marker弹出卡片式信息窗，包含封面图、菜名、店名、评分、标签、价格。点击卡片展开完整详情。

**地图样式**：支持标准、卫星、暗色三种样式切换，默认标准样式。暗色模式自动切换暗色地图。

**热力图**：统计视图下可开启美食热力图，直观展示美食密集区域。

## 4\.5 搜索与筛选

**全文搜索**：顶部搜索框支持菜名、店名、地址、备注的模糊匹配。输入即时搜索，高亮匹配关键词。支持搜索历史记录。

**高级筛选**：筛选面板支持多条件组合：

- 时间范围：今天/本周/本月/今年/自定义区间

- 标签：多选，包含任一/包含全部

- 评分：最低星级筛选

- 价格：自定义区间滑块

- 用餐类型：多选

- 只看收藏/只看有图

**排序方式**：最新优先、最早优先、评分从高到低、价格从高到低、距离当前位置由近到远。

## 4\.6 数据统计

**概览卡片**：总记录数、涉及餐厅数、总消费金额、平均评分、本月新增数。

**图表展示**：

- 月度趋势折线图：记录数量和消费金额按月统计

- 标签分布饼图：各标签记录占比

- 价格分布柱状图：不同价格区间的记录数

- 评分分布：各星级记录数

- 用餐类型占比

**热力图**：在地图上叠加美食密度热力层，直观发现美食聚集地。

## 4\.7 数据管理

**数据导出**：支持导出为JSON（完整数据，含图片Base64）或CSV（表格数据）。图片可单独打包为ZIP下载。导出文件包含版本信息，用于导入校验。

**数据导入**：选择之前导出的JSON文件，支持合并导入或覆盖导入。导入前预览数据，显示将新增/更新的记录数。

**自动备份**：每日首次打开应用时自动备份数据到浏览器IndexedDB，保留最近7天备份。支持手动触发备份。

## 4\.8 多人共享（简单实现）

支持好友间简单共享美食标记，无需注册账号，通过房间码机制实现小范围共享。

**用户标识**：首次使用时设置昵称（仅本地保存，无需密码），自动生成本地用户ID。不同用户的Marker在地图上用不同颜色区分，悬停显示用户名。

**共享组（房间）**：

- **创建房间**：用户点击"创建共享组"，输入组名，系统生成6位数字房间码

- **加入房间**：输入6位房间码即可加入，无需审核

- **退出房间**：随时退出，退出后不再看到该组共享记录

- **成员列表**：查看组内所有成员昵称和加入时间

**记录可见性**：新建记录时可选择：

- **仅自己可见**（默认）：只有自己能看到

- **共享到当前组**：组内所有成员都能在地图上看到

**视图切换**：顶部可切换"我的记录"/"全部记录"视图。查看共享记录时，Marker显示创建者颜色，信息窗显示"由 XXX 分享"。只能编辑/删除自己的记录，他人记录只读。

设计原则：极简实现，不做复杂权限。没有账号体系、没有角色管理、没有邀请审核，适合朋友/家人间小范围使用。

# 5\. 业务流程

## 5\.1 新建记录主流程

```text
开始
  ↓
1. 用户点击"新建记录"或按 Ctrl+N
  ↓
2. 右侧抽屉滑出空白表单
  ↓
3. 【可选】拖拽/选择图片上传 → 自动压缩+生成缩略图
     → 自动提取EXIF中的GPS和时间 → 询问是否自动填充位置
  ↓
4. 填写菜名*、店名*（必填，实时校验）
  ↓
5. 选择位置：
     a) 输入地址关键词 → 高德联想 → 点击选中
     b) 点击"定位我" → 浏览器定位 → 自动落点
     c) 直接在地图点击落点 → 逆地理编码获取地址
     → 可拖拽Marker微调
  ↓
6. 【可选】选择标签、用餐类型、填写人均价格
  ↓
7. 【可选】选择评分（1-5星）、填写备注、标记收藏
  ↓
8. 点击"保存"或 Ctrl+S
  ↓
9. 前端校验通过 → POST /api/entries（multipart）
  ↓
10. 后端：校验 → 保存图片 → 开启事务 → 写入数据库 → 关联标签
     → 失败回滚：删除已上传图片
  ↓
11. 返回成功 → 关闭抽屉 → 地图飞到新点 → Marker缩放动画高亮
  ↓
结束
```

## 5\.2 编辑记录流程

从详情页点击"编辑"打开表单，预填所有数据。修改后点击保存，后端对比变更：图片有新增则上传，有删除则标记待清理；标签变更则更新关联表。更新updated\_at时间戳。

## 5\.3 删除与撤销流程

```text
用户点击删除
  ↓
弹出确认对话框（可跳过，直接软删除）
  ↓
确认 → 标记 deleted_at 时间戳（软删除）
  ↓
列表/地图立即移除该记录
  ↓
底部显示 Toast："已删除 1 条记录" + "撤销"按钮（5秒倒计时）
  ↓
┌─ 用户点击撤销 → 清除 deleted_at → 记录恢复显示
│
└─ 5秒后 → 撤销按钮消失
         → 后端异步任务：30天后永久删除记录和关联图片
```

## 5\.4 批量操作流程

列表页长按或点击多选按钮进入批量模式。支持全选/反选、批量删除、批量添加标签、批量导出。批量操作显示进度条，完成后汇总结果。

## 5\.5 数据导入流程

1. 用户选择JSON备份文件

2. 前端解析文件，校验格式和版本

3. 显示预览：将导入X条记录，其中Y条是新增，Z条将更新（按ID匹配）

4. 用户选择"合并"或"覆盖全部现有数据"

5. 开始导入，显示进度条

6. 导入完成，显示成功/失败统计，失败记录可下载错误报告

## 5\.6 校验规则汇总

|字段|规则|
|---|---|
|菜名|必填，1\-100字符，前后去空格|
|店名|必填，1\-100字符|
|经纬度|必填，GCJ\-02坐标系，中国范围内经纬度校验|
|图片|最多9张，单张≤10MB，格式jpg/png/webp/heic|
|评分|可空，1\-5整数|
|人均价格|可空，0\-9999整数|
|标签|最多10个，单个标签≤10字符|
|备注|可空，最多2000字符|

# 6\. 数据模型

## 6\.1 数据库设计

使用SQLite，单文件数据库。以下为主要表结构设计。

### 6\.1\.1 美食记录表 food\_entries

|字段|类型|约束|说明|
|---|---|---|---|
|id|INTEGER|PK AUTOINCREMENT|主键|
|dish\_name|TEXT|NOT NULL|菜名|
|restaurant\_name|TEXT|NOT NULL|店名|

## 8\.4 关键技术决策

**数据库选择 node:sqlite**：Node 24内置，无需编译原生模块，部署简单。API与better\-sqlite3基本一致，性能满足单用户场景。如遇问题可无缝切换到better\-sqlite3。

**图片处理 sharp**：服务端压缩和生成缩略图，减少存储占用和加载时间。支持HEIC格式转换为JPEG。

**状态管理 Zustand**：轻量、无boilerplate，适合中小型应用。配合React Query做服务端状态缓存。

**PWA支持**：v1\.5版本添加Service Worker，支持离线访问已加载数据、添加到主屏幕。

## 10\.1 设计原则

**内容优先**：地图是主角，UI元素克制不抢眼。工具栏和侧栏使用毛玻璃半透明效果，不遮挡地图内容。

**即时反馈**：每个操作都有视觉反馈，点击有涟漪效果，加载有骨架屏，成功/失败有Toast。

**视觉愉悦**：美食主题使用温暖色调，圆角卡片，柔和阴影，微动效提升质感。

## 11\.2 加载状态

- **首屏加载**：地图骨架屏 \+ 侧栏骨架卡片，不显示空白

- **列表加载更多**：底部显示加载指示器，滚动到底部自动加载

- **图片上传**：上传中显示进度条，失败显示重试按钮

- **保存中**：保存按钮显示loading，禁用重复点击

- **导入/导出**：显示进度条和当前处理项，支持取消

## 11\.3 错误状态

|错误场景|提示方式|用户操作|
|---|---|---|
|网络错误|顶部横幅"网络连接失败，请检查网络"|自动重试按钮|
|图片上传失败|图片位显示错误图标 \+ "点击重试"|单张重试或重新选择|

## 11\.4 边界情况处理

- **图片过大**：前端自动压缩，超过10MB提示"图片过大，已自动压缩"

- **图片格式不支持**：提示"仅支持JPG/PNG/WebP/HEIC格式"

- **重复提交**：保存按钮loading态，防止重复提交

- **离线操作**：v1\.5版本支持离线查看已加载数据，新建记录排队等待联网同步

- **数据量过大**：超过1000条记录时，列表使用虚拟滚动，地图Marker强制聚合

# 17\. 多人共享功能（v1\.0 简单实现）

设计原则：极简实现，不做复杂账号体系。适合朋友/家人小范围共享美食地图，上线部署后几个人可以一起用、互相看到标记。

## 17\.1 功能说明

**用户标识**：首次使用时设置昵称即可，浏览器自动生成并保存用户UUID（无需密码、无需注册）。不同用户的Marker用不同颜色区分，悬停显示昵称。

**共享组（房间）**：

- **创建房间**：点击"创建共享组"，输入组名，系统生成6位房间码

- **加入房间**：输入6位房间码即可加入，无需审核

- **退出房间**：随时退出，退出后不再看到该组共享记录

- **成员列表**：查看组内所有成员昵称和加入时间

**记录可见性**：新建记录时选择：

- **仅自己可见**（默认）：只有自己能看到

- **共享到当前组**：组内所有成员都能在地图上看到

**视图切换**：顶部可切换"我的记录"/"全部记录"。共享记录显示"由 XXX 分享"标记，只能编辑/删除自己的记录，他人记录只读。

## 17\.4 简单业务流程

**创建并加入房间**：

1. A点击"创建共享组"，输入"成都美食小分队"，得到房间码"ABC123"

2. A把房间码发给B、C

3. B、C打开应用，输入"ABC123"加入

4. 所有人都能看到彼此标记为"共享"的美食记录

**权限说明**：

- 只能编辑/删除自己创建的记录

- 创建者可以解散组（解散后所有共享记录变为私有）

- 没有管理员、没有角色、没有邀请审核
